Router administration & manual setup

Discover your router to open its local administration page.

SF2AiS does not collect or store your router password or automate vendor-specific router login forms. Sign in directly in the router page. UPnP IGD normally lets SF2AiS request a temporary rule without your router login once TLS is ready. If UPnP is disabled or unsupported, create the rule manually using the instructions below.

Show manual port-forwarding instructions
  1. Sign in to your router administration page and open Port Forwarding, NAT, Virtual Server or Firewall Rules.
  2. Reserve the SF2AiS computer LAN address not detected in DHCP / Address Reservation.
  3. Create one rule: external port 443, internal address not detected, internal port 443, protocol TCP.
  4. Save/apply the rule. Do not forward port 8000, Docker, SSH, or router administration.
  5. Only test from a separate network (for example, mobile data with Wi-Fi off) after TLS is working and the public hostname/DDNS is configured.

Router menus differ by manufacturer. If the router is behind another router or carrier-grade NAT, forwarding may also be required upstream or may not be possible on the current connection.
